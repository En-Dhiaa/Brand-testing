# Brand-testing — استوديو ألوان الشعار (الجامعة السعودية الإلكترونية)

منصة رقمية تفاعلية متكاملة للمشاركة المجتمعية في اختيار وتخصيص ألوان الهوية البصرية الرسمية للجامعة السعودية الإلكترونية.

تتيح المنصة للزوار والطلاب ومنسوبي الجامعة تخصيص كل عنصر من عناصر الشعار الرسمي بدقة متناهية، واختيار التدرجات اللونية والخلفيات، وتجربة الألوان ومعاينتها فورياً، ثم اعتماد المقترح وقفله نهائياً للحصول على معرف عام فريد (`LC-XXXXXX`) يشارك في التصويت العام مع حماية تامة ضد التكرار والتلاعب.

---

## 🌟 الميزات الرئيسية

1. **شعار رسمي حقيقي 100% بدون أي عناصر نائبة:**
   - استخدام مباشر لبيانات المتجهات (SVG Paths & Polygons) من ملفات الشعار الرسمية (`all logo parts.svg` بأبعاد `1027.35 × 826.06`).
   - تقسيم دقيق لـ 6 عناصر قابلة للتخصيص المستقل:
     - الرمز الأوسط (حرف Y)
     - الجناح الأيسر (حرف E)
     - الجناح الأيمن (حرف U)
     - النقاط الملكية (المربعات الثلاثة العلوية)
     - النص العربي (مخطوطة: الجامعة السعودية الإلكترونية - 44 مسار و6 مضلعات)
     - النص الإنجليزي (SAUDI ELECTRONIC UNIVERSITY - 26 حرفاً)

2. **استوديو التخصيص التفاعلي (`/customize`):**
   - اختيار الأجزاء عبر النقر المباشر على الشعار التفاعلي أو من قائمة العناصر.
   - منتقي ألوان متقدم يدعم HEX مخصص مع لوحات معتمدة (العنابي الملكي، الأخضر الزمردي، الذهبي الفاخر، الكحلي، وغيرها).
   - محرك تدرجات لونية (Gradients) خطية ودائرية مع التحكم بالزوايا وتدرجات الألوان.
   - تحكم كامل بالخلفيات (شفافة، فاتحة، داكنة، مخصصة، متدرجة) مع شبكة شطرنج للمعاينة الشفافة.
   - سجل التراجع والإعادة (Undo / Redo / History).
   - تكبير وتصغير (Zoom In / Zoom Out) ومعاينة بكامل الشاشة (Fullscreen).
   - تصدير فوري عالي الدقة (PNG بخلفية شفافة / ملونة بدقة 2048px، و JPG بجودة 92%).

3. **اعتماد المقترحات وقفلها النهائي (`/proposals/[id]`):**
   - توليد معرف عام عشوائي فريد لكل مقترح بنمط `LC-XXXXXX`.
   - قفل غير قابل للتعديل (Immutable Snapshot): لا يمكن لأي مستخدم عام تعديل أو حذف المقترح بعد اعتماده.
   - عرض تفصيلي لشرائح الألوان المستخدمة مع إمكانية نسخ كود HEX بنقرة واحدة.
   - توليد رمز استجابة سريعة (QR Code) للمشاركة السريعة عبر الجوال.

4. **المشاركة المجتمعية والتصويت المحمي:**
   - نظام تصويت منفصل: صوت واحد فقط لكل زائر مع حماية على مستوى الجلسة وقاعدة البيانات (`Unique Constraint`).
   - نظام إعجاب مستقل (Like / Unlike Toggle).
   - قسم تعليقات تفاعلي مع تعقيم صارم ضد ثغرات XSS وحد أقصى للأحرف.

5. **لوحة الإحصائيات العامة والتحليلات (`/results`):**
   - إجمالي المقترحات، الأصوات، الإعجابات، والتعليقات المعتمدة.
   - عرض المقترح الأكثر تصويتاً والمقترح الأكثر إعجاباً.
   - تحليل توزيع ترددات الألوان المقترحة وتطبيع أكواد HEX.

6. **لوحة تحكم المشرفين المحمية (`/admin`):**
   - تسجيل دخول آمن بكلمة مرور مشفرة عبر `bcrypt` وتوكن جلسة موقع بـ `HMAC-SHA256` (Web Crypto متوافق مع Edge Runtime).
   - إدارة حالات المقترحات (نشر، إخفاء، حذف).
   - الإشراف على التعليقات ومراجعتها.
   - التحكم بإعدادات النظام العامة (فتح/إغلاق التصويت، المشاركة، التعليقات).

## 🛠 التقنيات المستخدمة

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5 (Strict Mode)
- **Styling:** Tailwind CSS + Vanilla CSS (RTL-first)
- **Database ORM:** Prisma ORM مع SQLite محلي (`dev.db`)
- **Icons:** Lucide React
- **Validation:** Zod v3
- **Security:** Bcryptjs, Web Crypto HMAC-SHA256, HTTP-Only Cookies, XSS Sanitization
- **QR & Export:** qrcode, HTML5 Canvas 2048px Rasterizer

## 🚀 التشغيل المحلي

### 1. المتطلبات
- Node.js 18 أو أحدث (تم اختباره على Node v20 و v24)
- npm

### 2. تثبيت الحزم
```bash
npm install
```

### 3. إعداد وتحديث قاعدة البيانات
```bash
npx prisma db push
npm run seed
```
> سيتم إنشاء الحساب الإداري الافتراضي:
> - **البريد الإلكتروني:** `admin@seu.edu.sa`
> - **كلمة المرور:** `AdminSEU@2026!`

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000` (أو المنفذ المتاح).

### 5. بناء الإنتاج والتشغيل
```bash
npm run build
npm run start
```

## 🧪 الاختبارات الآلية

### اختبارات الوحدة (Unit Tests):
```bash
npm test
```
تشمل 7 اختبارات تفصيلية:
- تشفير والتحقق من كلمات المرور عبر `bcrypt`.
- التحقق وتوقيع توكنات الجلسة واكتشاف التلاعب بالرموز المشفرة.
- تطبيع أكواد HEX (تحويل الأكواد المختصرة والصغيرة إلى `#RRGGBB` موحد).
- التحقق الصارم من صحة صيغ الألوان عبر التعابير النمطية Regex.
- التحقق من مخطط بنية مقترح شعار الجامعة الرسمي عبر Zod.
- رفض المدخلات غير الصالحة والألوان المشوهة.
- تعقيم التعليقات وفرض القيود الأمنية.

### اختبار التحقق الشامل من البداية للنهاية (E2E Smoke Test):
```bash
npm run test:e2e
```
يتحقق آلياً من:
1. استجابة الصفحة الرئيسية والوسوم الرسمية.
2. جاهزية استوديو التخصيص.
3. إنشاء مقترح جديد وتوليد معرف `LC-XXXXXX`.
4. قفل المقترح وعدم قابليته للتعديل.
5. الإعجاب وإلغاء الإعجاب بنجاح.
6. تسجيل الصوت الأول ومنع تكرار التصويت من نفس الجلسة (قاعدة الصوت الواحد).
7. نشر وتعقيم التعليقات.
8. استخراج التحليلات والإحصائيات وأكثر الألوان شيوعاً.
9. تسجيل دخول المشرف واستلام التوكن الآمن.
10. إدارة المقترحات واستعراض لوحة التحكم.

## 🔒 الأمان والمطابقة

- **RTL-First:** واجهة مستخدم عربية أصيلة متوافقة مع الهوية السعودية.
- **Strict Single Vote:** حماية صارمة لمنع التلاعب في الأصوات.
- **XSS Protection:** تعقيم جميع النصوص المدخلة من المستخدمين.
- **No Hardcoded Passwords:** كلمات المرور مشفرة ومحمية بـ Salted Bcrypt Hash.
- **PWA Ready:** ملف `manifest.json` وأيقونات متوافقة لتثبيت التطبيق على الهواتف الذكية.
